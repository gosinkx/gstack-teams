✅ **9 Professional Engineering Roles**
- Planning Phase: Product Partner, CEO Reviewer, Eng Reviewer
- Development Phase: Staff Engineer, Debugger, Design Reviewer
- Release Phase: QA Lead, Release Engineer, Doc Engineer
- Additional: Eng Manager (anytime)

✅ **Complete 3-Phase Workflow**
- Planning → Development → Release
- Serial, parallel, and on-demand scheduling modes

✅ **Project Documentation**
- README.md with quick start guide
- CHANGELOG.md
- LICENSE (MIT)
- Complete role prompts and project conventions

### Installation

**Option 1: Clone from GitHub**
```bash
git clone https://github.com/tison-g/gstack-teams.git
cp -r gstack-teams/* ~/.workbuddy/skills/gstack-teams/
```

**Option 2: Download ZIP**
Download the gstack-teams.zip from this release and extract to your WorkBuddy skills directory.

### Quick Start

After installation, use natural language to trigger:

- "创建规划团队"
- "帮我做 code review"
- "帮我跑完整发布流程"
