# gstack Agent Teams — 子 Agent 假死事件记录

> 本文件记录所有子 agent 假死事件，用于分析根因和持续改进 skill。
> 每次发生子 agent 假死时，必须在此文件追加一条记录。

---

## 记录模板

```markdown
### [日期] [时间] — [Agent 名称] 假死

- **任务阶段**：[规划期/开发期/发布期]
- **Agent 角色**：[角色名称]
- **max_turns 设置**：[有/无，具体值]
- **假死时正在执行**：[最后已知的工具调用或操作]
- **距离上次上报时长**：[秒]
- **是否设置 timeout**：[是/否，具体值]
- **是否交互式命令**：[是/否，命令]
- **恢复方式**：[优雅关闭成功/强制关闭/用户手动重启]
- **根因分析**：[为什么假死]
- **改进措施**：[下次如何避免]
```
